# Contributing to NeuroDrive

Contributions, bug reports, accessibility improvements, tests, and documentation fixes are welcome.

## Before you open a pull request
1. Search existing Issues and Discussions to avoid duplication.
2. For changes to architecture, progression rules, or data formats, open an Issue first.
3. Keep changes scoped and include automated tests when applicable.
4. Do not commit music, sample recordings from third parties, proprietary game art/sounds, credentials, telemetry, or personal data.
5. Document newly introduced dependencies and their licensing compatibility with GPLv3.
6. Explain how to reproduce and verify the change. The project may not have a working build until its bootstrap phase is complete.

## Pull requests
- Describe intent, changed components, and test evidence.
- Keep a change focused on one issue or one task when possible.
- Avoid unrelated refactors or production services.
- Never upload personal local music files, audio metadata from private libraries, or developer secrets.

Unless a separate agreement says otherwise, contributions are submitted under the repository's GNU GPLv3 license; contributors retain their copyright. Third-party code must be properly attributed and license compatible.

Respectful, technically focused discussion is expected.
