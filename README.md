# NeuroDrive

**You are the character. Real life is the game.**

NeuroDrive is a free, open-source Windows desktop application that brings together local music, task-focused work sessions, real-life goals, and personal progress. It is designed to help people begin work, finish meaningful tasks, and recover sustainably.

**Status:** planning / initial development. No production-ready download yet.

## Principles
- Real-life improvement, not pay-to-win. No paid XP or boosts.
- Local-first and offline-first: user data stays on the device by default.
- Music belongs to users: the repository and application do **not** include music tracks.
- Users select local music folders and manually tag tracks for multiple situations (focus, motivation, recovery, etc.).
- Results matter more than hours or streaks. Breaks are not punished.
- All core features are free; donations may be offered without gameplay advantage.

## Planned desktop features
- Local library and playback for user-selected audio files.
- Manual multi-tagging and playlist selection by sprint phase.
- Tasks and work sprints, including optional Excel and Markdown task integration.
- Floating mini-player, notifications, and system tray.
- GLOBAL progression for participation, CURRENT progression for real-life goals, PERSONAL progression for measured abilities.
- Achievements, original coin/chest rewards, local analytics, experiments, and recovery reminders.

No site, accounts, leaderboards, social integrations, online competition, Google Sheets, or server backend are in the current development scope.
