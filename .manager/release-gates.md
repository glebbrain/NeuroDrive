# Release Gates

## Foundation gate
- License and product constraints committed.
- Repository structure and task protocol usable by Codex.
- The next phase can be started unambiguously.

## Desktop gate (future)
- Supported target Windows/.NET matrix confirmed and tested.
- Dependency licenses checked against GPLv3.
- Music/metadata from users never included in releases.
- Offline installation and app launch tested.

## Production gate (future)
- Data migration and recovery verified.
- Critical UI and task flows pass acceptance tests.
- Error handling, logging privacy, accessibility, packaging and updates verified.
- No invented test evidence or release promises.
