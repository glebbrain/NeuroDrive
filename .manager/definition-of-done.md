# Definition of Done

A task is DONE only if:
1. Scope and all acceptance criteria are satisfied.
2. Relevant tests and formatting/static checks pass or an explicitly permitted substitute is documented.
3. Changes avoid committed personal data, copyrighted music, and secrets.
4. Developer docs and relevant contracts are updated.
5. Verification evidence is written next to the task.
6. No unrelated TODO tasks or phases were modified.

If any condition cannot be verified, leave it unchecked and mark BLOCKED in the report.
