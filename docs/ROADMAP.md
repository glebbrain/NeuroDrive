Milestones define working product outcomes. Phases are scoped tasks for Codex; each TODO item has StoryPoints <= 3.

| --- | --- | --- |

| M1 Music | ND-05 MUSIC-PROFILES | Manual multi-tags, playlists, repeat/cooldown |
| M2 Productivity | ND-06 TASK-ENGINE | Tasks, completion reports, local journal |

| M2 Productivity | ND-09 DESKTOP-UI | Main window, mini-player, tray |

| M3 RPG | ND-11 GLOBAL-PROGRESSION | Engagement levels without farming |
| M3 RPG | ND-12 CURRENT-PROGRESSION | Goals, pathways, verifiable milestones |
| M3 RPG | ND-13 ACHIEVEMENTS | Local badges and reward collection |

No website, cloud sync, leaderboard, Google Sheets, multiplayer, or social integration is in the current delivery roadmap. These are separate possible future projects, not implied dependencies.
