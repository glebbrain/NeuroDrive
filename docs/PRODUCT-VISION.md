# Product Vision

## Problem
Starting a difficult task, staying focused, and stopping at a healthy time can be hard. Traditional productivity tools track time or tasks separately; games provide feedback without necessarily improving real-life outcomes.

## Solution
A local-first Windows productivity companion combining user-supplied music, structured work sprints, tasks, motivational rewards, measured personal development, and recovery.

## Core user journey
1. Add a local folder of music; index compatible files and their metadata.
2. Manually tag one track with any number of purpose tags; optionally create custom tags.
3. Choose a concrete task and a sprint profile.
4. Play tagged tracks for appropriate sprint phases; retain manual override.
5. Finish task with a brief result and evidence as required; earn appropriate rewards.
6. Log progress, review analytics, and take a break.
7. Optionally compare local experiments to learn which routine helps.

## Scope boundaries
- No music in application or repository; music source is user's local folders.
- No automatic track emotion/purpose classification in MVP. External tagging import may be added later.
- No mandatory account, website, cloud, leaderboard, competition, Google Sheets, or linked social networks.
- Future personal exercises and article quizzes must distinguish completion rewards from demonstrated improvement.
- Excel XLSX task integration and Markdown TODO import are planned; local journal must preserve events when files are locked.

## First release criterion
A usable, stable, offline Windows application with music, task sprints, reward feedback, local progress analytics, and privacy controls.
